# Grocery Store Management System using SQL 

## 📌 Project Overview
This project performs a comprehensive analysis of a grocery store database using SQL to uncover key business insights.
It focuses on transforming raw transactional data into meaningful information that supports data-driven decision-making across customers, products, sales, and operations.

---

## 🛠️ Tools Used
- SQL (MySQL)
- MySQL Workbench

---

## 📂 Dataset
The dataset includes:
- Customers
- Orders
- Order Details
- Products
- Categories
- Suppliers
- Employees

## ⚠️ Challenges
- Managing complex relationships across multiple tables using JOIN operations
- Performing aggregations across large datasets
- Handling date-based analysis for trend identification
- Ensuring data integrity using primary and foreign keys

## 🚀 Conclusion
This project demonstrates the practical application of SQL in analyzing real-world business data.
It successfully identifies customer behavior patterns, high-performing products, and sales trends, showcasing strong skills in data analysis, querying, and relational database design.
